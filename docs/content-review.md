# Danh sách duyệt nội dung phản ứng (CHEMIMON)

**Tổng quan:** 0 phản ứng chờ duyệt, 0 cặp chất đầu vào, 48 phản ứng đã duyệt.

**Cặp rẽ nhánh** (cùng cặp chất, sản phẩm khác nhau tùy điều kiện; cần ít nhất 8):

- Bộ đã duyệt: 9 (C + O₂; C + SiO₂; CO + Fe₂O₃; Cu + O₂; Fe + O₂; Fe₂O₃ + H₂; H₂O + Mg; K + O₂; Na + O₂)
- Bộ chờ duyệt: 0
- Gộp cả hai: 9 (C + O₂; C + SiO₂; CO + Fe₂O₃; Cu + O₂; Fe + O₂; Fe₂O₃ + H₂; H₂O + Mg; K + O₂; Na + O₂)

Cách duyệt: gửi danh sách id được duyệt, rồi chạy `approve <id...>`. Tỷ lệ là số lượng chất thứ nhất / chất thứ hai, sắp theo id chất tăng dần.
